AutoxVision instructions

Return to app

AutoxVision trains recognition of the next course feature from first-person course-walk video. It shows a short prompt, hides it, and asks you to identify or mentally reproduce the nearest upcoming segment. The selected video and practice data stay in your browser.

Start a session

  1. Select Video and choose a browser-playable local course video. A new file resets the course range to its beginning and end.
  2. Choose a mode, then set prompt length, speed, and the number and playback style of choices.
  3. Watch the prompt once. After the blackout, click the video that begins nearest in course time after the prompt.
  4. Use the green prompt-through-answer replay to reinforce the connection, then click the prompt pane or press Space or R for the next trial.

Recall modes

Random recall mode
Samples an independent prompt location for each trial.
Sequential recall mode
Starts a newly loaded course at the beginning. Each correct continuation becomes the next prompt; the sequence wraps to Course range start near the end. Use Sequential position to jump.
Weak spots mode
Begins with random sampling, then favors locations with a higher first-answer miss rate.
Mental lap mode
Hides the gallery. Visualize the continuation, then use Show answer. Choose sequential order or independent random starts in the controls.

Timing

  • Prompt length is displayed viewing time. A 5-second prompt lasts 5 seconds at every speed; increasing speed covers more source-video time.
  • Continuation choices have the same displayed duration as the prompt.
  • Answer gap sets the minimum and maximum source-video time skipped between prompt end and the correct gallery continuation. Near Course range End, the maximum used for that trial is limited only by the remaining local space.
  • Choice wait sets the blackout time before gallery choices become active.
  • Wrong choices are sampled outside the protected prompt-to-answer interval.
  • In mental lap, the continuation is immediate and has the same duration as the prompt. Show answer plays the continuous prompt-plus-continuation sequence.
  • Course range is a dual slider for source-video Start and End. Prompts and every gallery choice stay inside this region.

Gallery playback

One-by-one
Plays each choice separately with black frames between choices and keeps only the active choice decoder mounted.
Hover
Plays a choice while its tile is hovered or keyboard-focused.
All play
Prepares every choice, then starts and loops them together at the selected Speed.

Loop pause holds the end of each Hover or All play clip before it restarts. Clicking anywhere on a video submits that answer; an incorrect choice remains available for another attempt.

All play requires the browser to decode every visible choice in parallel. For unusually demanding source files, One-by-one and Hover use less decoding capacity.

Prompt controls

Replay prompt
Replays the current prompt when Replay is enabled.
Show answer
Reveals the correct continuation. It is available without a gallery choice in mental lap.
Replay full answer
After a sequential answer has played, replays the complete prompt-through-correct-continuation sequence.
Course start
Restarts sequential recall or mental-lap practice at the active Course range start.
Next prompt
Begins the next trial after an answer replay. Clicking the black prompt pane does the same thing.

Controls and presets

  • Speed applies from 0.25x through 14x to prompt, gallery, and reveal playback. Above 4x, the app skips forward when a decoder falls behind so clip duration and covered course time remain correct; very high rates therefore present sampled frames.
  • Replay permits prompt replay while answering.
  • Sound enables correct and incorrect feedback tones.
  • Prompt masking can blur and/or darken a selected height upward from the bottom of ordinary prompt playback. The height is a fixed frame boundary that can be aligned manually with a stable horizon. Masks also apply to Replay prompt, but never to gallery clips or answer replays.
  • Sequential position moves practice through the part of Course range where a complete prompt, minimum Answer gap, and continuation fit. It is disabled in other modes.
  • Controls that do not apply to the selected session mode remain visible but are disabled and greyed out.
  • The preset menu at the bottom applies grouped settings. Built-in presets preserve prompt masks. Any direct edit changes the preset to Custom; Save preset stores one reusable local preset, including masks, without changing the course range.
  • Drag the horizontal divider to resize prompt and gallery. Notes and controls can be collapsed horizontally.

Feedback, history, and notes

  • A correct answer adds one point, gives green feedback, and plays the prompt-through-answer reveal.
  • An incorrect answer subtracts one point, marks the selected tile red, and keeps the trial active.
  • Miss history stores recent incorrect trials for retry. Selecting a miss restores that trial without changing the score again.
  • Notes autosave locally near the current prompt time. High scores, settings, and weak-spot statistics also persist in local browser storage.

Keyboard controls

1-8
Select the corresponding gallery choice.
Space or R
Replay the prompt, or start the next prompt after a reveal.
A, P, or Enter
Show the answer when reveal is available.
S
Restart sequential or mental-lap practice at the course start.
M
Toggle feedback sound.

Privacy and compatibility

The selected video is not uploaded. The browser reads it through a temporary local object URL.

Playback depends on the codecs supported by the current browser. MP4/H.264 is broadly supported; MOV playback varies with its contained codec. A decode failure is reported in the app.

Reloading or closing the page clears the selected file reference. Select the video again to continue; locally saved settings, scores, and notes remain available.
