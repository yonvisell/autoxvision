AutoxVision instructions

Return to app

AutoxVision is a temporal-recall trainer for first-person autocross course-walk video. It presents a prompt from the source video, hides it, and asks for the continuation. All processing and saved practice data remain in the browser.

Start a session

  1. Select Video, then choose a browser-playable local course video.
  2. Set the prompt duration, number of choices, playback speed, and session mode.
  3. Watch the prompt once. After the blackout and choice wait, select the continuation.
  4. After the correct reveal, click the prompt pane or press Space or R for the next trial.

Recall modes

Random recall
Samples an independent prompt time for each new trial.
Sequential recall
Advances through the course in source-time order.
Weak spots
Uses random sampling until enough history exists, then favors slower or missed prompt locations.
Mental lap
Hides the gallery. Run the continuation mentally, then use Show answer. Sequential order advances by one prompt duration; Random starts independently resamples each trial.

Timing

  • Prompt sets duration T for prompt and continuation clips.
  • Response gap sets the allowed source-time interval between prompt end and the correct gallery continuation in recall modes.
  • Wrong choices are sampled outside the protected prompt-to-answer interval.
  • In mental lap, the continuation is immediate and has the same duration as the prompt. Show answer plays the continuous prompt-plus-continuation sequence.
  • Start and End restrict the source-time region used for prompt starts.

Gallery playback

One-by-one
Plays each choice separately with black frames between choices.
Hover
Plays a choice while its tile is hovered or keyboard-focused.
All play
Loops all choices simultaneously.

Selecting a tile always submits that answer. Incorrect choices remain available for another attempt.

Prompt controls

Replay prompt
Replays the current prompt when Replay is enabled.
Show answer
Reveals the correct continuation. It is available without a gallery choice in mental lap.
Course start
Restarts sequential recall or mental-lap practice at the configured Start time.

Controls and presets

  • Choice wait sets the blackout interval before choices play.
  • Speed applies to prompt, gallery, and reveal playback.
  • Replay permits prompt replay while answering.
  • Sound enables correct and incorrect feedback tones.
  • Controls that do not apply to the selected session mode remain visible but are disabled and greyed out.
  • Built-in presets set related controls together. Any direct edit changes the preset to Custom. Save preset stores one reusable local preset.
  • Drag the horizontal divider to resize prompt and gallery. Notes and controls can be collapsed horizontally.

Feedback, history, and notes

  • A correct answer adds one point, gives green feedback, and plays the prompt-through-answer reveal.
  • An incorrect answer subtracts one point, marks the selected tile red, and keeps the trial active.
  • Miss history stores recent incorrect trials for retry. Selecting a miss restores that trial without changing the score again.
  • Notes autosave locally near the current prompt time. High scores, settings, and weak-spot statistics also persist in local browser storage.

Keyboard controls

1-8
Select the corresponding gallery choice.
Space or R
Replay the prompt, or start the next prompt after a reveal.
P or Enter
Show the answer when reveal is available.
M
Toggle feedback sound.

Privacy and compatibility

The selected video is not uploaded. The browser reads it through a temporary local object URL.

Playback depends on the codecs supported by the current browser. MP4/H.264 is broadly supported; MOV playback varies with its contained codec. A decode failure is reported in the app.

Reloading or closing the page clears the selected file reference. Select the video again to continue; locally saved settings, scores, and notes remain available.
